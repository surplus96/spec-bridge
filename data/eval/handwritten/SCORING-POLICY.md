# 합성 평가 후보셋 채점 정책 v2

작성: 2026-10-06 · 적용: dataset_revision 2, 정답 schema_version 2 · origin: synthetic

이 정책은 현재 6건의 라벨과 채점 단위를 고정한다. W1 온톨로지의 필수 속성·열거값·허용 범위 검증은 별도로 남아 있다. 실제 제조사 문서 전체에 적용할 도메인 규칙이 아니다.

## 입력과 평가 자료

- 모델 입력은 [inputs](inputs/)의 `DOC-001.md`~`DOC-006.md` 본문뿐이다. 합성임을 명시한 정상 기술 사양 본문이며 클래스 약칭 파일명·작성 메모·정답은 포함하지 않는다.
- [dataset-manifest.yaml](dataset-manifest.yaml)은 평가기만 읽는다. 모델에는 `input_id`와 `input_text`의 파일 내용만 전달한다. 경로 매핑·doc_id·answer·manifest 전체를 전달하지 않는다.
- `HW-*.spec.md`는 편집 원본이다. 이 파일명을 모델에 전달하지 않는다. 편집 후 `inputs/` 사본도 함께 갱신하며 감사 스크립트로 동일성을 확인한다.
- 정답 YAML, 이 정책, ANSWER-KEY, 관찰 메모, 검토 보고서는 모델 입력 및 테스트셋 기반 사전·프롬프트 튜닝에서 제외한다. 공통 스키마·별칭·단위 정책은 W1/개발셋에서 정의하고 테스트 실행 전에 고정한다.
- DOCX/PDF가 생성되기 전에는 텍스트 추출 평가만 가능하다. Markdown 결과를 PDF 파서 성능으로 보고하지 않는다.

## 속성 값의 채점 단위

대표 속성 55개와 SEP 추가 조건 값 1개를 합쳐 **56개 정답 단위**로 센다. 같은 값의 반복 출현은 속성 TP를 늘리지 않는다.

- 정답 단위의 키는 `(문서, 속성, 조건/기준)`이다. 정규 단위로 환산한 값과 요구되는 기준이 일치해야 TP다.
- SEP 처리량은 380/700 cSt at 50 °C 각각의 정답 단위다. 380 조건의 3,600 l/h를 대표값으로 둔 것은 이 평가셋의 저장 정책이다. 700 조건의 2,100 l/h도 정상 정답이며 반드시 회수 대상이다. 두 조건을 합쳐 E5 불일치로 판단하지 않는다.
- COMP capacity는 FAD와 본문 기준 온도·절대압을 보존한다. max_pressure는 gauge 기준이다. 기준 조건의 절대압을 작동 게이지압으로 대체할 수 없다. `reference_conditions`는 capacity 정답 단위의 메타데이터이며 추가 TP 단위가 아니다.
- 2S rated_power는 MCR, 4S rated_power는 continuous_engine_shaft 기준이다. 4S 값을 발전기 전기 출력으로 채점하지 않는다. 기준 메타데이터와 value가 함께 일치해야 한다.
- 치수는 length/width/height 전체를 하나의 객체로 채점한다. 세 값 중 일부만 맞으면 해당 객체는 불일치다. TC 범위도 min/max와 2행정·과급기 1대 기준을 함께 하나의 정답 단위로 센다.
- 연료 목록은 순서를 무시한 집합으로 비교한다. 문자열 열거값은 정답의 정규값으로 비교하며 실제 허용값 여부는 W1에서 대조한다.
- 중량은 `weight_basis`가 있으면 dry와 본문 포함 범위를 보존한다. 이 세 문서에서 Weight/Net weight를 dry_weight로 채점할 수 있는 이유는 **본문이 dry를 명시하기 때문**이다. 일반적인 Weight 동의어 규칙으로 확장하지 않는다.
- 틀린 값/기준은 FP 1건과 해당 정답의 FN 1건으로 센다. 누락은 FN이다. 입력 파싱 또는 모델 호출 실패도 정답 분모에서 제외하지 않는다.
- 동일 키·동일 값의 반복 예측은 하나로 합친다. 같은 키에 서로 다른 값이 있으면 맞는 값은 최대 TP 1건, 추가 잘못된 값은 각각 FP다. 정답 조건을 빠뜨린 값은 조건이 요구되는 정답 단위와 매칭하지 않는다.

## 단위와 수치 비교

| 표기 | 이번 후보셋의 해석 |
|---|---|
| m³/h, m3/h | 동일 유량 단위 |
| rpm, r/min | 동일 회전수 단위 |
| cm → mm | 10배 |
| t → kg | 미터톤 1,000배 |
| ton → kg | 4S 본문이 metric tonnes 및 1,000 kg를 명시한 경우만 1,000배 |
| bhp → kW | 2S 본문이 정의한 기계식 마력 계수 0.7457 사용; 다른 원본의 BHP 정의를 덮어쓰지 않음 |
| barg, bar g | bar 단위와 pressure_basis: gauge를 함께 보존 |
| L/B/H | 이 문서의 B(breadth)는 width |
| H/L/W | 표기 순서를 length/width/height 객체로 재배열 |

2S rated_power의 환산값에만 정답의 `match_tolerance_rel: 0.001`을 적용한다. 판정은 `abs(예측-정답) / abs(정답) <= 허용오차`다. 나머지 값은 정규화 후 수치 일치를 요구한다. 부동소수점 표현 차이만 극소 오차로 처리하고 임의의 제품 공차를 추가하지 않는다. 형식명의 BMH 공백/하이픈 변형은 같은 제조사·본문의 동일 제품 언급에 한해 정규값으로 묶는다. 모든 모델의 하이픈을 무조건 삭제하지 않는다.

## 출현 위치의 채점

- 제품 자체의 속성 값을 직접 진술하는 위치를 기록한다. 표뿐 아니라 제품 설명·용도에 명시된 seawater, air-cooled, heavy fuel oil, generating sets 등의 표현도 포함한다.
- 같은 절 안에서 반복된 하나의 의미 진술은 한 출현으로 취급한다. 같은 절 안에 서로 다른 값이 실제 존재하면 각각 기록한다. 줄 번호·절·표 행은 별도로 보존한다.
- 다른 속성의 표 행에 HFO가 직접 쓰인 경우에는 처리량 조건의 medium 근거로도 기록한다. 하나의 문자열이 서로 다른 정답 속성에 근거가 될 수 있다. 출현 위치 지표는 `(속성, 조건, 위치)` 단위이며 속성 추출 F1과 분리한다.
- 공급 구성품·보조 기기의 속성을 주 제품의 속성 출현으로 세지 않는다. 예: alternator의 8-pole은 엔진 실린더 수가 아니다. 환산 계수의 kW는 실제 rated_power 출현이 아니다.
- 단어만 있는 문서 제목, 속성명, 부정 문장, 형식 코드의 숫자, 장비의 일반 설명만으로 값을 유추한 곳은 출현으로 세지 않는다. 라벨 완전성은 의미 검토 사항이며 문자열 존재 검사만으로 증명하지 않는다.
- 현재 위치는 절/표 행 기준이다. DOCX/PDF 생성 후 `pdf_page`를 실제 파일 기준으로 채운다. null을 페이지 0 또는 정확한 위치로 처리하지 않는다.

## 함정 목록 없이 오추출을 평가하는 방법

`distractors`와 본문 뒤의 함정·설계 메모는 제거했다. 정상 사양서에 있는 기준 조건, 실린더당 출력, 주파수, 로터 회전수, 구성품 언급은 유지했다.

- 요청한 출력 스키마의 속성에 정답과 다른 값을 매핑하면 일반 FP/FN 규칙으로 평가한다. 잘못된 문서 클래스는 클래스 매핑 지표로 평가한다. 별도 함정 가산점·감점은 없다.
- 스키마 밖 속성을 반환하면 출력 계약 위반을 별도 보고한다. 속성 추출 F1은 요청한 스키마 안의 예측으로 계산한다. 평가 후 스키마 밖 출력을 유리한 속성으로 재분류하지 않는다.
- 구성품 형식명이 없는 언급은 has_component의 식별된 제품 관계로 만들지 않는다. `Make and type to be confirmed`는 형식명이 아니다. 이는 이 후보셋의 관계 계약이며 모든 BOM 추출 작업의 규칙은 아니다.
- 향후 온톨로지에 과급기 회전수 같은 속성을 추가하면 평가 **전에** 라벨·정답 단위·버전을 함께 갱신한다. 기존 정상 정보를 영구적인 비대상 값으로 고정하지 않는다.

## 아직 확정하지 않은 평가

`expected_status: null`, `missing_required: null`, `validation_status: ontology_pending`은 W1 검증 계약이 아직 없다는 뜻이다. 정상 문서로 의도해 작성했지만 허용 범위·필수 항목을 실제 온톨로지로 검사한 상태는 아니다. null을 pass 또는 빈 누락 목록으로 바꾸어 해석하지 않는다.

현재 문서에는 E1~E7 양성 라벨과 비교할 등록 목록이 없다. 따라서 오류 검출 재현율 및 중복·유사 성능을 보고하지 않는다. 구성품 관계와 manufactured_by는 속성 F1의 56개 분모에 넣지 않고 별도 평가한다. 사용자 검토 서명과 W1 스키마 적합성, 렌더링 파일 검증이 끝나기 전 상태는 **수정된 평가 후보셋**이다.
