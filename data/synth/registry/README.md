# 가상 기존 등록 제품 입력 목록

2026-10-07 · DATA-DEV-DRAFT · origin: synthetic

[dev.jsonl](dev.jsonl) 90개와 [test.jsonl](test.jsonl) 60개, 총 **150개 등록 입력 레코드**를 작성했다. 각 클래스 25개이며 [manufacturers.json](manufacturers.json)에 가상 제조사 4개를 기록했다. 실제 운영 DB에서 내보낸 자료가 아니라 합성 원장으로 만든 비교 입력이다.

제품 ID, 클래스, 제조사/모델, 정상 속성·조건·단위·범위와 제품 관계를 담는다. 작성용 family_id·split·role·variant_index·primary_case는 레코드에 포함하지 않았다. 공개적인 제품 분류·식별자는 비교 입력이며 질의 문서의 정답 라벨과 구별한다.

개발에는 dev 목록만 사용한다. test 목록은 평가 시 비교 대상으로 제공하되 사전·프롬프트·임계값 튜닝에 사용하지 않는다. 전체 목록을 합쳐 개발 실험을 하지 않는다. 별도 제품 사실의 출처 위치는 없으며 기존 제품 카탈로그 입력으로 취급한다.

등록 목록은 파일로 작성했지만 최종 검토·해시 고정 전이다. 제품 관계는 합성 연결이며 실제 설계 적합성을 주장하지 않는다. 중복·유사 정답은 지정된 쌍에 한정하며 미지정 제품을 자동 음성으로 해석하지 않는다.
