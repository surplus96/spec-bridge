# FourStrokeEngine 범위 정의

상태: 정의표 작성 완료 · 경로: Equipment → Engine → FourStrokeEngine · origin: synthetic

원본에서 확인한 선박 추진·발전용 4행정 엔진을 대상으로 한다. application으로 용도를 구별하며 클래스는 추가하지 않는다. 엔진 자체와 alternator/완성 genset의 기술 사양을 구별한다. 원본의 제조사 리브랜딩 안내는 일반 제조사 별칭을 자동 확정하는 근거로 확대하지 않는다.

공통 정의와 Engine 공유 속성을 상속한다. F1/F2는 REF-4S-01/02, S는 HW-4S-001이다. 원본 관찰은 사용자 의미 검증 대기다.

등록 필수 후보는 maker/model_designation/application 및 전체 출력·속도·실린더 수다. shaft/electrical 기준이 없는 출력은 unknown으로 보존하고 같은 정격이라고 확정하지 않는다. 실린더당 출력×실린더 수 계산은 조건·구성이 같다고 확인된 경우의 검증 후보이며 원문 직접 관찰을 대체하지 않는다.

## 합성 후보셋 연결

현재 11개 대표 속성을 모두 연결했다. S는 continuous_engine_shaft를 명시하므로 Generator kWe로 변환하지 않는다. 건조 중량은 본문의 metric tonnes 정의로 환산한다. 8-pole/60 Hz는 발전 조건 문맥이며 현재 정답에는 별도 엔진 속성으로 추가하지 않는다. 과급기 형식 미정은 확정 has_component 관계가 아니다.

## 미해결 사항

- U-02: 출력·속도·주파수·정격 종류를 연결하는 조건 구조.
- U-07: 모호한 ton의 자동 환산 보류 및 연료 표기 사전 검증.
- U-08: 엔진 단품/발전기 포함 모듈의 제품 범위, 형식 미정 구성품 처리.

검증 사례 후보: 축출력/전기 출력 구별, 실린더당 출력·극수 오매핑 방지, 엔진/발전기 포함 중량과 치수 범위 보존.
