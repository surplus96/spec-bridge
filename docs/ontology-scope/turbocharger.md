# Turbocharger 범위 정의

상태: 정의표 작성 완료 · 경로: Equipment → EngineComponent → Turbocharger · origin: synthetic

주 제품이 과급기인 기술 문서를 대상으로 한다. 적용 엔진의 출력·사이클이 언급되어도 엔진 제품으로 매핑하지 않는다. 원본에 있는 axial/radial 표현은 turbine/compressor 중 어느 대상을 수식하는지 확인한 뒤 연결한다.

공통 정의를 상속한다. T1/T2는 REF-TC-01/02, S는 HW-TC-001이다. 원본 관찰은 사용자 의미 검증 대기다.

| ID | 의미·대상 | 자료형 / 정규 단위·차원 | 필수 여부·이유 | 조건·기준 | 근거 |
|---|---|---|---|---|---|
| `turbocharger_type` | 명시된 과급기 형식; 대상 부위를 함께 보존 | enum 후보+대상 메타데이터 / 없음 | 필수(안): 제품 형식 식별 | axial/radial 후보; turbine/compressor 구별이 불명확하면 검토, 임의 동일화 금지 | T1 p.1, T2 p.8~9; S 1.3/표1은 axial-flow turbine |
| `applicable_engine_power` | 해당 과급기가 적용되는 엔진 출력 | number 또는 range(min,max)의 조건별 관찰 목록 / kW·동력 | 필수(안): 적용 능력 비교 | 2/4행정, per_turbocharger 및 정격/최대 기준 명시값 보존; T1 단일값을 임의 범위로 만들지 않음 | T1 p.2, T2 p.8; S 표2/3.1 |
| `bearing_type` | 과급기 자체의 명시된 베어링 형식 | enum/string 후보 / 없음 | 선택: 구성·정비 특징 | plain 관찰 후보; 다른 제품의 베어링 설명을 가져오지 않음 | T1 p.2; S 표4 |

등록 필수 후보는 maker/model_designation/turbocharger_type/applicable_engine_power다. 과급기 형식의 분류 축은 산업 표준으로 확정하지 않고 원문 표현과 대상 부위를 유지한다. 적용 출력의 엔진 조건은 중요한 메타데이터지만 미기재 문서는 unknown으로 보존하며 표 열이나 문맥을 자동 보충하는 규칙은 사용자 검증 후 정의한다.

## 합성 후보셋 연결

현재 7개 대표 속성은 공통 4개와 고유 3개에 연결된다. S의 적용 출력은 min/max, 2행정, 과급기 1대 기준을 명시한다. dry 중량·완성 유닛 치수는 S의 명시 기준이고 T1의 일반 Weight를 건조 중량으로 일반화하지 않는다. B를 width로 연결하는 원문 치수 관찰도 도면 대상 범위를 함께 확인한다.

## 확장 보류

T1 p.2의 과급기 로터 최대 회전수, T2 p.8의 압력비·온도는 원본에 있는 정상 기술 정보다. 현재 평가 계약에 포함되지 않으므로 이번 정의표에서는 **확장 후보**로 기록하고 속성 ID를 확정하지 않는다. 로터 회전수를 엔진 rated_speed에 넣지 않는다. 속성 수 목표 8~12개만으로 채택하지 않고 등록 목적·자료형·두 원본의 의미 대응을 검토한다.

## 미해결 사항

- U-02: 단일 출력과 출력 범위의 자료형, 엔진 사이클/per-unit 기준 보존.
- U-03: 일반/건조 중량과 대상 범위.
- U-09: TC 속성 수 7개, 로터 회전수·압력비 확장 채택 여부와 평가 버전 영향.

검증 사례 후보: 적용 엔진 출력과 과급기 자체 속성 구별, 2/4행정 열 구별, 단일값과 범위값 보존.
