# TwoStrokeMainEngine 범위 정의

상태: 정의표 작성 완료 · 경로: Equipment → Engine → TwoStrokeMainEngine · origin: synthetic

현재 원본에서 확인한 선박 주추진용 2행정 엔진을 대상으로 한다. 명시된 작동 사이클과 주 제품의 용도에 근거해 매핑한다. rpm 크기나 형식명 숫자만으로 2행정이라고 확정하지 않는다. 과급기의 적용 대상 엔진 설명도 엔진 자체의 제품 사양과 구별한다.

공통 정의와 Engine 공유 속성을 상속한다. E1/E2는 REF-2S-01/02, S는 HW-2S-001이다. 원본 관찰은 사용자 의미 검증 대기다.

| `rated_power` | 엔진 전체의 지정 정격 출력 | number의 조건별 관찰 목록 / kW·동력 | 필수(안): 제품 정격 비교 | MCR/NMCR/SMCR/CMCR·정격점·실린더 구성 보존; kW/cyl를 전체 출력으로 대체 금지 | E1 p.23/51, E2 p.29/38; S 표4/3.1 |

등록 필수 후보는 maker/model_designation 및 전체 출력·대응 회전수·실린더 수다. 구체적인 정격 종류와 단위 기준은 값의 의미에 포함한다. E1 p.23의 BHP 정의와 S의 기계식 bhp 정의는 다르므로 문서별 정의를 보존하고 무조건 하나의 계수를 적용하지 않는다. 실제 출력·MEP 허용 범위는 이번 단계에서 정의하지 않는다.

## 합성 후보셋 연결

현재 10개 대표 속성을 모두 연결했다. rated_power는 MCR, rated_speed는 같은 MCR 조건이며, fuel_types는 본문의 HFO/MGO다. has_component는 S 3.2의 TTA-70을 식별한다. 출력이 TC 적용 범위 안에 들어간다는 사실만으로 실제 엔진/과급기의 적합성을 보증하지 않는다.

## 미해결 사항

- U-02: 정격점·구성별 출력/속도 묶음과 연료 역할 표현.
- U-07: bhp/BHP·톤·회전수 단위의 문서별 정의와 확인 절차.
- U-08: 식별된 구성품의 제조사·형식·연결 대상 처리.

검증 사례 후보: 실린더당 출력 오매핑 방지, 정격점별 정상값 보존, 서로 다른 마력 정의와 회전수 대상 구별.
