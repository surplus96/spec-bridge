# 데이터셋 완성을 위한 문서 준비 목록

2026-10-07 · 현재 범위: 6개 클래스의 합성 데이터셋 · 근거: D-006~D-008

**현재 확보한 원본 12건(클래스별 2건)으로 이번 합성 데이터셋 작성은 계속 진행할 수 있다. 추가 원본 기술 명세서가 현재 작업의 필수 선행 조건은 아니다.** 실제 허용 범위·제조사 모델 해석·기계적 호환성을 평가 목표로 추가할 때는 해당 주장을 뒷받침하는 원본과 사용자 의미 검증이 필요하다.

## 원본 자료의 선택적 보강

아래는 기존 [근거 목록](ontology-scope/reference-evidence.yaml)에서 미확정된 부분을 해결하기 위한 문서 유형이다. 새 제조사·클래스를 늘리기 위한 목록이 아니다. 기존 원본의 관련 페이지나 사용자 보유 자료에 충분한 설명이 있으면 새 파일을 확보할 필요가 없다.

| 보강 문서 유형 | 확인할 내용 | 현재 자료·쟁점 | 필요해지는 경우 |
|---|---|---|---|
| 펌프 모델별 성능표/곡선·단위 설명 | 유량과 양정/차압의 동일 운전점, 압력 정의 | REF-PUMP-01/02, Pump U-01/U-02 | 합성 값의 물리적 성능 적합성까지 검사할 때 |
| 압축기 용량 기준·전동기 사양 페이지 | FAD/charging 기준, 작동/최대압, shaft/consumption/motor 출력의 차이 | REF-COMP-01/02, U-02/U-04/U-05 | 실제 표현의 동등성·환산을 규칙으로 채택할 때 |
| 분리기 모델별 설치/전동기·배출 기능 명세 | 주 분리기 모터 정격, 모듈 포함 범위, 청정 기능, 점도 기준 | REF-SEP-01/02, U-03/U-04/U-06 | 현재 합성 모터 출력·청정 라벨에 실제 사양 근거를 붙일 때 |
| 엔진 정격표와 단위 정의 페이지 | 전체/실린더당 출력, 축/발전기 출력, 정격점, bhp/BHP 정의 | REF-2S-01/02·REF-4S-01/02, U-02/U-07 | 실제 원문 기준의 환산과 정격 비교를 확정할 때 |
| 과급기 형식/적용표·구성도 | axial/radial의 대상 부위, 엔진 사이클, per-unit 범위, 단품/모듈 중량 | REF-TC-01/02, U-03/U-09 | 실제 적용 범위와 구성품 적합성까지 평가할 때 |
| 공급 범위·조립 BOM/중량·치수 도면 | 구성품 모델 식별, 중량/치수 포함 경계 | 원본별 도면·범위 정의 U-03/U-08 | 실제 BOM 호환성 또는 도면 해석을 정답으로 요구할 때 |

원본을 보강한다면 문서명·판본·취득일·URL·해시와 정확한 PDF 페이지/표를 기록한다. 표기 존재 확인과 의미 검증은 구별하며 verified_by는 사용자만 작성한다. 실제 허용 범위는 출처와 검증 없이 임의로 채우지 않는다. 단순히 원본 수를 늘리는 것은 이번 데이터셋 완료 조건이 아니다.

| 제품 원장·가상 제조사/모델 목록 | 184개 제품 설계값 작성 | 문서와 별도 검토, 수정 시 버전/해시 갱신 |

| 표기 변형 출처 목록 | 40건의 출처 표기 57개 출현 목록 작성 | 적용 표기 확대 시 원본 문구·페이지 대조; 세부 환산 계약 추가 |
| 중복·유사 정답 | 중복 6·유사 4쌍 실제 파일 해시로 연결 | 지정 쌍 범위 검토·확정 |
| BOM | 4건 YAML·읽기용 문서 작성 | 합성 관계의 기술적 의미 검토 |
| 채점·분할·재생성 명세 | 계획과 정답 계약 작성 | 오류 채널 분모·변환 허용차, 파일 생성 절차·버전 고정 |
| 데이터셋 검토 패키지 | [검토 패키지](dataset-review-package.md) 작성·후보 해시 기록 | 사용자 검토 기록·지적 반영 및 확정 |

BOM·등록 목록·비교 정답은 현재 범위에서는 합성으로 작성할 수 있다. 사용자에게 실제 운영 데이터나 추가 원본을 반드시 제공해 달라고 요청할 단계는 아니다. 외부 분류 코드와 기능 로더·파서·추출기 구현도 데이터셋 완성의 선행 조건이 아니다.

## 평가 범위를 추가할 때 별도로 필요한 자료

전체 등록 목록 대비 new/duplicate/similar 정확도나 검색 top-k를 평가하려면 지정 10쌍 외에 **음성/신규 사례, 다중 유사 후보 정답, 판정 기준**이 필요하다. 현재 10쌍만으로 전체 검색 정확도를 주장하지 않는다. 이 자료도 합성으로 구성할 수 있으며 현재 지정 쌍 평가와 구별해 범위를 결정한다.

레이아웃·스캔 이미지·OCR 손상에 대한 성능까지 평가하려면 해당 파일과 위치 정답이 필요하다. 현재 계획은 생성된 PDF·Excel·DOCX이며 실제 스캔 자료나 OCR 오류셋은 필수 목표에 포함하지 않았다.
