# 데모 대본 (약 30초)

README에 넣을 화면 녹화 대본이다. 녹화는 사용자가 한다. 결과 파일은 `docs/media/demo.gif`다.

## 준비

```bash
cd ~/projects/spec-bridge
npm --prefix web run build
OFFLINE=1 SPEC_BRIDGE_APP_DIR=var/demo uv run uvicorn spec_bridge.api.app:app --host 127.0.0.1 --port 8000
```

- 새 작업 폴더(`var/demo`)를 쓴다. 작업 목록이 비고, 등록 목록은 개발 분할 기본값으로 시작한다.
- 브라우저 창은 1440×900 정도로 맞추고, 확대 비율은 100%로 둔다.
- 녹화 전에 SYN-011을 한 번 처리해 두면 모델이 미리 메모리에 올라간다(warm). 처리한 작업은 취소한다. 문서 처리에 1분 가까이 걸리므로 녹화본에서는 대기 구간을 자르거나 빠르게 감는다.

## 장면

| 초 | 화면 | 조작 | 자막(선택) |
|---|---|---|---|
| 0–3 | 작업 목록 | `data/synth/inputs/SYN-011.docx` 업로드 | 합성 사양서 업로드 |
| 3–6 | 처리 중 → 검토 화면 | (대기 구간 빨리 감기) | 로컬 모델로 추출·검증 |
| 6–11 | 검토 화면 3분할 | 가운데 사실 하나(예: `rated_power`)를 누르면 왼쪽 원문이 강조된다 | 모든 값은 원문 위치를 가진다 |
| 11–16 | 사실 편집 | 값 하나를 고치고 사유를 적어 저장한다. 수정 표시(✎)와 이력이 보인다 | 수정은 같은 규칙으로 다시 검사 |
| 16–19 | 하단 막대 | **신규 등록**을 누른다. "신규 제품으로 등록되었습니다." 안내와 제품 링크가 뜬다(링크를 누르면 근거·수정 이력이 있는 제품 상세) | 사람이 확인한 뒤 등록 |

| 23–27 | 검토 화면 | 상단 "등록 차단 1", 오른쪽 "중복" 탭에 **동일 제품** 카드(빨간 테두리) | 동일 제품으로 판정, 등록 차단 |
| 27–30 | 하단 막대 | 연결 대상이 동일 제품으로 미리 선택돼 있다. **연결**을 누른다 | 새로 등록하지 않고 연결 |

## 녹화와 변환

1. macOS `Cmd+Shift+5`로 브라우저 창 영역을 녹화한다(`.mov`).
2. 대기 구간을 잘라 약 30초로 맞춘다.
3. GIF로 바꾼다. `ffmpeg`가 있으면 아래처럼 한다. 폭 960px, 12fps 기준으로 수 MB가 된다.

```bash
mkdir -p docs/media
ffmpeg -i demo.mov -vf "fps=12,scale=960:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" docs/media/demo.gif
```
